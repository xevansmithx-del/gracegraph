# Scientific boundaries

GraceGraph 0.1.0a1 is research software at empirical `N=0`.

It can establish bounded software facts such as byte identity, exact inventory
membership, deterministic replay, and whether a documentary record exists. It cannot
establish that a scientific claim is true merely because a file exists or a graph is
internally consistent.

Every evaluation fixes:

```json
{
  "biological_gate_closed": false,
  "empirical_n": 0,
  "experiment_authorized": false,
  "release_authorized": false,
  "target_selected": false
}
```

Consequently:

- biological claims abstain with `ABSTAIN_UNCALIBRATED`;
- human decisions and owner authorizations require accountable external action;
- computational results remain review-required until a registered semantic receipt
  adapter exists;
- a capsule hash establishes byte identity, not truth, independence, permission, or
  currentness;
- action rankings are bounded heuristics over a declared candidate set, not causal
  inference or globally optimal experiment selection;
- the software is not a medical device and does not provide diagnosis, treatment,
  dosing, clinical advice, or laboratory authorization.

The synthetic example intentionally supplies a documentary note to a declared
biological claim. GraceGraph records the note while refusing to promote the
biological claim. That refusal is the demonstration.
