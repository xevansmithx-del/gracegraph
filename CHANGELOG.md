# Changelog

All notable changes to GraceGraph are documented here.

## 0.1.0-alpha.2 — 2026-08-28

- Replace two README references to unbundled planning files with links to the
  bundled architecture and scientific-boundary documents.
- Preserve the alpha.1 source and release tag unchanged; alpha.2 supersedes it for
  documentation-integrity purposes without changing compiler semantics.

## 0.1.0-alpha.1 — 2026-08-28

- Add strict typed artifacts, claims, memory checks, and deterministic action triage.
- Add exact-member, canonical, no-clobber capsules with live-project replay.
- Fix the empirical boundary at `N=0` with no target, experiment, or release authority.
- Name unauthenticated static verification `PASS_SEALED_BYTES_ONLY` to prevent a
  semantic or authenticity interpretation.
- Reject symlinked and hard-linked memory databases and malformed capsule manifests.
- Add a synthetic public example, hostile tests, privacy checks, packaging, and CI.
